# 🎙️ PB Live - Party Audio & Live Streaming App

> Developed by **Official Tech Love PB**  
> Location: Batala, Punjab, India  

## 🚀 About the Project
**PB Live** is a real-time live streaming and multi-seat voice party application featuring 12-seat interactive audio rooms, persistent profile management, and custom room creation.

## ✨ Key Features
* **12-Seat Audio Rooms:** Real-time seat management and mic control.
* **Persistent Profile:** Local storage for user DP and names.
* **Gallery DP Picker:** Direct profile picture updates.
* **Modern Dark Theme:** Custom neon purple interface.

## 📱 How to Run
1. Install Flutter SDK.
2. Run `flutter pub get` to install dependencies.
